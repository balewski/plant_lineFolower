# September 24 robot assembly

The native FreeCAD files are the design sources; there are no builder scripts for them in this tree. Edit them in FreeCAD, then re-export the affected print plate (see [AGENTS.md](AGENTS.md)).

## Contents

| Path | Purpose |
| :--- | :--- |
| `main_lower_deck.FCStd` | Chassis with motor mounts, two motor clamps, three cable clamps, installed photo-sensor holder and hardware references |
| `main_pillars.FCStd` | Front and aft pillar frames standing on the deck |
| `main_upper_deck.FCStd` | Upper platform (Teensy/electronics), board retaining clamp, ammeter support |
| `main_roof.FCStd` | Conical roof |
| `main_photo_sensor.FCStd` | Standalone sensor holder, cover strip and buzzer holder |
| `main_overview.FCStd` | Assembled and exploded visualization, regenerated by `overview/build_overview.py`; see [overview/README.md](overview/README.md) |
| `print_*/` | Per-plate `export_print.py`, QIDIStudio `machine.json`, `process.json`, `filament.json` |
| `assets/` | `DejaVuSans.ttf`, used by `overview/build_overview.py` for its text labels |
| `tmp/` | Git-ignored working area for regenerable output (STLs, 3MFs, slices, previews, reports); safe to overwrite or delete |

## Rebuilding and checking

Run FreeCAD scripts with the bundled interpreter:

```sh
PYTHONPATH=/Applications/FreeCAD.app/Contents/Resources/lib \
/Applications/FreeCAD.app/Contents/Resources/bin/python <script>.py
```

- `print_*/export_print.py` exports closed STL meshes and a packed 3MF to `tmp/`, and fails if a mesh is not a closed manifold solid or its volume differs from the CAD solid by more than 0.1%.
- `overview/build_overview.py` rebuilds `main_overview.FCStd` from the current source files after design changes.
- Geometry checks do not establish physical stiffness or fit. Nothing is printed without the confirmation steps in [AGENTS.md](AGENTS.md).
